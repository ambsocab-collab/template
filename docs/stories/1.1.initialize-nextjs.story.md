## Dev Notes

### Tech Stack Requirements
- **Frontend Framework:** Next.js ^14.0 with App Router [Source: architecture/tech-stack.md]
- **Language:** TypeScript ^5.0 for type safety [Source: architecture/tech-stack.md]
- **Styling:** Tailwind CSS ^3.0 for utility-first CSS [Source: architecture/tech-stack.md]
- **Build Tool:** Next.js built-in SWC bundler [Source: architecture/tech-stack.md]
- **Package Manager:** npm or pnpm (project choice) [Source: architecture/tech-stack.md]

### Testing Standards
- **Testing Framework:** Jest for unit testing [Source: architecture/testing-strategy.md]
- **Frontend Testing Library:** React Testing Library for component tests [Source: architecture/testing-strategy.md]
- **Test Organization:** Tests in `/tests` directory with structure matching `/app` [Source: architecture/testing-strategy.md]
- **Test Pyramid:** 70% unit, 20% integration, 10% E2E tests [Source: architecture/testing-strategy.md]

### Project Structure Reference
- Project root: `next-sqlite-starter/`
- App code location: `app/` (Next.js 14 App Router)
- Configuration files: `tsconfig.json`, `next.config.js`, `tailwind.config.js`, `jest.config.js`, `playwright.config.ts`
- Tests location: `tests/` with subdirectories for `unit/`, `integration/`, `e2e/`
[Source: architecture/project-structure.md]

### Coding Standards to Follow
- All TypeScript code must be type-safe
- Use ESLint for code quality
- Use Prettier for consistent formatting
- Environment variables must be validated (will be covered in future stories)
- Never commit `.env.local` or sensitive credentials
[Source: architecture/coding-standards.md]

### Build & Development Process
- Dev server: `npm run dev` (runs on port 3000)
- Production build: `npm run build` (must complete without errors)
- Type checking: Use strict TypeScript mode to catch errors early
- Linting: All code must pass ESLint rules before commit
[Source: architecture/tech-stack.md and project-structure.md]
