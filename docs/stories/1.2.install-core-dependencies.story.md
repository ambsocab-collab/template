# Story 1.2: Install Core Dependencies

## Status
Ready

## Story
**As a** developer,
**I want** to install all core dependencies needed for authentication, database, payments, and UI components,
**so that** the project has all required libraries configured and ready for implementation of subsequent features.

## Acceptance Criteria

1. [ ] All dependencies installed via `npm install` without errors
2. [ ] No peer dependency warnings in npm output
3. [ ] `package-lock.json` is generated and committed to git
4. [ ] `npx next info` confirms Next.js 14+ is installed
5. [ ] `npm list` shows all packages without errors
6. [ ] All specified libraries are at their latest compatible versions

## Tasks / Subtasks

- [ ] Task 1: Install Production Dependencies (AC: 1)
  - [ ] Run: `npm install @clerk/nextjs@latest clerk`
  - [ ] Run: `npm install drizzle-orm better-sqlite3`
  - [ ] Run: `npm install stripe`
  - [ ] Run: `npm install shadcn-ui`
  - [ ] Run: `npm install tailwindcss postcss autoprefixer`
  - [ ] Run: `npm install zod`
  - [ ] Verify: No error messages during installation

- [ ] Task 2: Install Development Dependencies (AC: 1)
  - [ ] Run: `npm install --save-dev @types/better-sqlite3`
  - [ ] Run: `npm install --save-dev drizzle-kit`
  - [ ] Run: `npm install --save-dev jest @testing-library/react`
  - [ ] Run: `npm install --save-dev playwright`
  - [ ] Run: `npm install --save-dev @playwright/test`
  - [ ] Verify: No error messages during installation

- [ ] Task 3: Verify Installation (AC: 2, 4, 5)
  - [ ] Run: `npm list` and verify no errors in output
  - [ ] Check: No peer dependency warnings in console
  - [ ] Run: `npx next info` and confirm Next.js 14+ installed
  - [ ] Run: `npm run type-check` (from Story 1.1) and verify no errors
  - [ ] Verify: All key packages appear in `package.json`

- [ ] Task 4: Commit Dependencies (AC: 3)
  - [ ] Run: `git add package.json package-lock.json`
  - [ ] Run: `git commit -m "feat: install core dependencies"`
  - [ ] Verify: Both files are tracked in git

### Why These Specific Libraries

All dependencies listed are from the architecture tech-stack specification and are mandatory for this project:
- **Clerk** eliminates custom authentication complexity and provides social login ready
- **Drizzle ORM** provides type-safe database access with excellent TypeScript support
- **SQLite** requires zero setup and is sufficient for MVP with clear upgrade path
- **Stripe** is industry standard with PCI compliance handled
- **shadcn/ui** provides minimal dependencies with full control over component customization
- **Zod** ensures runtime validation of user input and API responses
- **Testing Stack** (Jest, RTL, Playwright) follows modern React testing best practices

[Source: architecture/tech-stack.md]

### No Breaking Changes Expected

The existing project structure from Story 1.1 remains intact. These are purely additive installations with no configuration changes required at this stage. Package versions will be locked in `package-lock.json` for reproducible builds.

### Important Notes

- All installations should be done via npm (not pnpm or yarn unless project specifies otherwise)
- The `package-lock.json` file MUST be committed to git for reproducibility
- If peer dependency warnings appear, do NOT ignore them - investigate and resolve before proceeding
- Keep all package versions as they resolve naturally from `@latest` tags
- Avoid manually specifying versions unless there are known incompatibilities
