## Dev Notes

### Clerk Authentication Architecture

**Clerk Integration Approach:**
Clerk handles all authentication complexity including:
- User signup/login/logout flows
- Email verification
- Password reset
- Session management with HTTP-only cookies
- Multi-factor authentication support (optional)
- Social login ready (OAuth support)
[Source: architecture/tech-stack.md]

**Middleware Protection Pattern:**
Protected routes are defined using `clerkMiddleware` with `createRouteMatcher`. This ensures:
- Dashboard routes (`/(dashboard)(.*)`) require authentication
- API routes (`/api/user(.*)`, `/api/subscription(.*)`) require authentication
- Public routes (landing page, sign-up, sign-in) are accessible without auth
[Source: architecture/frontend-architecture.md#protected-route-pattern]

### Environment Variables

**Public Key (NEXT_PUBLIC_ prefix):**
- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`: Safe to expose to frontend, required for Clerk UI
- This key is visible in browser and git is acceptable

**Secret Key (no prefix):**
- `CLERK_SECRET_KEY`: Must NEVER be exposed to client
- Must be in `.env.local` and added to `.gitignore`
- Will be injected into production environment via hosting platform (Vercel)
[Source: architecture/security-performance.md, coding-standards.md]

### Security Considerations

**Cookie Management:**
- Clerk automatically uses HTTP-only cookies for token storage
- No need to manually handle JWT tokens in localStorage (prevents XSS)
[Source: architecture/security-performance.md#authentication-security]

**Session Management:**
- Clerk handles session refresh automatically
- User sessions auto-expire based on Clerk's configured timeout
- `SignOutButton` component ends user session immediately
[Source: architecture/security-performance.md#authentication-security]

**Route Protection:**
- Middleware runs on every request before reaching page components
- Failed auth redirects to configured sign-in URL
- Protected API routes can call `auth()` to verify session
[Source: architecture/frontend-architecture.md]
